# ARGUS

### *Because “it’s probably fine” is not a security strategy.*

ARGUS is a **CI/CD security and vulnerability prioritization platform** that brings security scanner findings into one place and helps figure out:

> **“Okay, but which one should we actually fix first?”**

### What we're building

*  Scan code, dependencies & secrets
*  Collect findings from security tools
*  Normalize and organize the chaos
*  Prioritize vulnerabilities based on context
*  Show everything in a dashboard
*  Add AI later, because apparently humans aren't tired enough

### Planned Stack

**Trivy · Semgrep · Gitleaks · Python · SQLite · Flask · GitHub Actions · Ollama**
